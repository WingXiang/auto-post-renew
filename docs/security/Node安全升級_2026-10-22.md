# Node 安全升級

Vercel 設定 Node major 24.x；minor／patch 由平台供應。目標為安全版 24.22.1，不能僅憑建置成功或 major 設定宣稱已修補。

專案 engines、.node-version、.nvmrc 與 npm devEngines 對齊修補目標；原依賴與功能保持原樣。伺服器私有日誌 Node.js runtime 記錄 process.version、execPath、OpenSSL；不建立公開診斷 API、不輸出秘密值。

部署後需觸發既有的唯讀 Function，從 Runtime Logs 確認實際版本，再驗證主要頁面。不要為版本驗證呼叫付費 AI、發布貼文、寫入金流或啟用 n8n 工作流。若平台仍供應較舊 patch，需保留未完成狀態，不能自行替換平台 runtime。
